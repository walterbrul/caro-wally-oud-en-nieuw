# Oud & Nieuw met Caro & Wally

Een eenvoudige mobiele uitnodigings- en RSVP-pagina.

## Nog in te stellen
1. Open `index.html`.
2. Vervang `VUL_HIER_JULLIE_PROJECT_URL_IN` door de Supabase Project URL (zonder `/rest/v1/`).
3. Vervang `VUL_HIER_JULLIE_PUBLISHABLE_KEY_IN` door de Supabase Publishable key.
4. Configureer de Supabase policies en maak een beheeraccount aan voordat je de site openbaar maakt.

## Belangrijk
Deze eerste versie is een basisprototype. De openbare bezoekers kunnen aanmeldingen en hapjes toevoegen en alle bezoekers kunnen de openbare lijsten bekijken. Beheerders kunnen inloggen en verwijderen. Stel Supabase Row Level Security correct in en maak alleen beheerdersaccounts aan via het dashboard; schakel openbare registratie uit. Publiceer niet voordat de SQL-beveiligingsstappen zijn gecontroleerd.
